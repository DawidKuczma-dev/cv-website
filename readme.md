# 🪪 Interaktywne CV – Dawid Kuczma

Nowoczesne, interaktywne CV stworzone w HTML, SCSS i JavaScript, które prezentuje mnie jako software developera w dynamicznej formie. Projekt łączy w sobie funkcjonalność, styl i zaawansowane efekty interfejsu użytkownika.


## 🔗 Demo

👉 [Interaktywne CV – demo online](https://dawidkuczma-dev.github.io/cv-website/)

## ⚙️ Technologie

- HTML5
- SCSS (Sass)
- JavaScript (Vanilla)

## 📁 Struktura folderów

```bash
📁 CV-Website
├── 📁 assets
|    └── 📁 images
│       ├── CountryExplorer1.png
│       ├── CountryExplorer2.png
│       └── ...
├── 📁 css
│   └── main.css
├── 📁 js
│   ├── main.js
│   ├── scroll-animations.js
│   └── sliders.js
├── 📁 scss
│   ├── _base.scss
│   ├── _education.scss
│   └── ...
├── index.html
└── README.md

📁 assets/images – zawiera zrzuty ekranu projektów, ikony i zdjecie profilowe
📁 js – skrypty odpowiedzialne za animacje
📁 scss – pliki źródłowe stylów (moduły SCSS)  
📁 css – skompilowany plik stylów dla strony

```
